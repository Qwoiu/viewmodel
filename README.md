# View Model — Forge 1.8.9

Клієнтський мод, який дозволяє змінити положення, поворот і розмір руки та предмета від першої особи. Усі зміни видно наживо, поки відкрите меню.

- Minecraft **1.8.9**, Forge **11.15.1.2318**
- Працює лише на клієнті — сервер не потребує мода, підходить для будь-яких серверів
- Не використовує Mixin і coremod: вся логіка в одному класі-обгортці над ванільним рендером руки

## Як користуватись

| Дія | Як |
|---|---|
| Відкрити меню | **Правий Shift** (змінюється в Керування → View Model) або команда `/viewmodel` (`/vm`) |
| Закрити меню | Esc, кнопка «Готово» або та сама клавіша |

У меню дві вкладки: **Предмет** (коли щось у руці) і **Порожня рука**. Меню саме відкривається на тій вкладці, яка зараз видна.

Слайдери: позиція X / Y, глибина Z, обертання X / Y / Z, розмір.

- Перетягування — змінити значення (біля нуля слайдер «прилипає»)
- **ПКМ** по слайдеру — скинути його
- **Колесо миші** по слайдеру — точна зміна (з **Shift** — крок ×10)
- Біла позначка на треку — значення за замовчуванням

Кнопки: «Скинути» (вся вкладка), «Копія →» (скопіювати вкладку в іншу), «Замах» (прев'ю анімації удару), «Мод: УВІМК/ВИМК».

Налаштування зберігаються автоматично в `config/viewmodel.cfg`.

## Збірка

Потрібно: **JDK 17** для запуску Gradle (JDK 21 не підходить для Gradle 8.1.1). JDK 8 для компіляції Gradle завантажить сам.

```bash
./gradlew build          # Windows: gradlew.bat build
```

Готовий мод: `build/libs/ViewModel-1.0.0.jar` (файл із `-dev` в назві брати не треба). Покладіть його в папку `mods` профілю Forge 1.8.9.

Запуск у dev-середовищі: `./gradlew runClient`.

### Збірка без встановлення JDK

Завантажте проєкт на GitHub — workflow `.github/workflows/build.yml` збере jar автоматично (вкладка Actions → Artifacts).

## Як це працює

`RendererInstaller` один раз підміняє поле `EntityRenderer.itemRenderer` на `ViewModelItemRenderer`. Той перед викликом ванільного `renderItemInFirstPerson` застосовує зсув, поворот і масштаб навколо звичайної точки руки, тому замах, їжа, блокування мечем, лук і мапа працюють як у грі.

Якщо інший мод уже підмінив `ItemRenderer` власним класом, View Model не втручається, щоб не ламати його, і меню покаже попередження.

## Відомі обмеження

- Швидкість і форму замаху цей мод не змінює — лише положення, поворот і розмір усієї руки.
- Мод не перевірявся в запущеній грі автором збірки. Якщо щось не працює, надішліть текст помилки з `logs/latest.log`.
